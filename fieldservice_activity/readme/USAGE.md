## Activities in a FSM Order

1. Go to the **Field Service** application.
2. Create or select an FSM Order.
3. Under the **Activities** tab, add as many activities as needed.

[FSM Order Activities Tab](../static/description/fsm_order_activity_tab.png)

## Activities in a FSM Order Template

1. As a user with Settings access, go to **Field Service > Configuration > Settings**.
2. Activate **Manage Order Templates** and save.

[Field Service Settings Manage Templates](../static/description/field_service_settings_manage_templates.png)

3. As a Field Service User, go to **Field Service > Master Data > Templates**.

[Field Service Templates](../static/description/field_service_template.png)

4. Under the **Activities** tab, create or add activities.

[Field Service Template Activities](../static/description/field_service_template_activities.png)

### Using a template with activities for a FSM Order

1. From the form view of an FSM Order, choose the template you created the activities for.
2. Under the **Activities** tab, the template activities are copied onto the order.
