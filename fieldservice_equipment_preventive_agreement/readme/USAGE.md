On an agreement, tab *Preventive Visits*: add one rule per visit type with its
interval and optional template. The equipments of the agreement get these
visits; visits added by hand on an equipment are kept.

On a preventive recurring order, *Preventive Agreement* restricts the visits to
the equipments of that agreement, which is also set on the generated orders.
Only agreements with equipments at the location are offered; a single one is
preselected. *Settings > Field Service > Require Agreement on Preventive Visits*
makes the field mandatory for the current company.
