This module manages typed, directional relations between Field Service
equipment records.

It keeps the standard Field Service equipment hierarchy and adds
functional, technical, or lifecycle links that cannot be represented by
a single ``parent_id``.

The module is generic and is not limited to IT or telephony.

Configuration
=============

Go to *Field Service > Configuration > Equipment Relations > Relation
Types*.

Create or adapt relation types with:

- a direct label;
- an inverse label;
- a technical code;
- a sequence;
- an active flag.

Usage
=====

Open a Field Service equipment and use the **Relations** smart button or
the **Relations** tab.

A relation contains:

- source equipment;
- relation type;
- related equipment;
- optional start and end dates;
- optional notes.

The inverse relation is displayed automatically on the related
equipment. The inverse row is read-only there; edit the original direct
relation to change it.

The standard ``parent_id`` / ``child_ids`` hierarchy remains available
for containment. Use this module for functional, technical, or lifecycle
relationships.
