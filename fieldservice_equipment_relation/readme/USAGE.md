Open a Field Service equipment and use the **Relations** smart button or the **Relations** tab.

A relation contains:

* source equipment;
* relation type;
* related equipment;
* optional start and end dates;
* optional notes.

The inverse relation is displayed automatically on the related equipment. The inverse row is read-only there; edit the original direct relation to change it.

The standard `parent_id` / `child_ids` hierarchy remains available for containment. Use this module for functional, technical, or lifecycle relationships.
