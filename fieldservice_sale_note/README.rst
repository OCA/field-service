Allows to register an internal note on Sales Orders, and pass it through
to the FSM Orders

**Table of contents**

.. contents::
   :local:

Usage
=====

- Go to Sales

- Create a new Quotation/Sale Order

- Set the FSM Location to be used

- On a Sale Order Line, select a product configured for field service
  orders

- On Other Information tab set the Intenal Note

- Confirm the Sale Order

- Now on Field Service Order the resolution is filled with internal
  notes of Sale Order

Known issues / Roadmap
======================
