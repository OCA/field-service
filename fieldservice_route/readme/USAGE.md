To use this module, you need to:

- Go to Field Service
- Create or select an order
- Assign it to a worker and schedule it
- Go to Field Service \> Dashboard \> Day Routes. A new record has been
  created.

To archive a route:

- Go to Field Service \> Master Data \> Routes and open the route
- Click Action \> Archive. The route is no longer shown in the list.
- To see archived routes again, use the Archived filter. From there
  they can be unarchived with Action \> Unarchive.
